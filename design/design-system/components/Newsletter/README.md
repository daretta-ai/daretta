# Newsletter

Il modulo di iscrizione alla newsletter: l'invito principale del sito e l'unico modulo in petrolio pieno.

- Fondo: gradiente 135° da `petrolio-acceso` a `petrolio-scuro`. Testo `carta`.
- Titolo in `punti-titolo`, minuscolo con il punto: «una mail al mese.» In fondo agli articoli: «ti è servito?»
- Una riga che promette poco e mantiene: frequenza e contenuto, niente entusiasmo.
- Campo `carta` con testo `cemento`; pulsante CTA `arancio` con testo `cemento` (vedi Pulsante).
- Il servizio di invio (Kit) è collegato dal sito; il modulo non chiede altro che l'email.
